# LCDmix

`LCDmix` is an R package for fitting mixtures of log-concave regressions,
designed for analyzing complex and heterogeneous data.

## Installation

You can install the development version of `LCDmix` from GitHub with:

``` r
# install.packages("devtools")
devtools::install_github("sang82496/LCDmix", subdir = "LCDmix")
```
